Version History

Below is a chronological list of all notable changes made to AI Mosaic Studio. We are committed to continuous improvement and transparency.

v2.0.0 — 1 September 2026
  • Major Update: Complete redesign of the user interface with a modern, dark theme.
  • New Feature: Manual Body Part Mapping – assign different tile sets to face, body, and background regions.
  • New Feature: 4K export resolution support.
  • New Feature: WEBP export format support.
  • Improvement: Significantly faster mosaic generation algorithm.
  • Improvement: Enhanced colour matching accuracy using CIELAB colour space.
  • Improvement: Better progress tracking with a detailed progress bar.
  • Bug Fix: Fixed issue with image upload on Safari browsers.
  • Bug Fix: Resolved memory leak during large tile set processing.
v1.5.0 — 15 June 2026
  • New Feature: Auto Set Images – AI automatically assigns tiles to regions.
  • New Feature: Theme toggle (dark/light mode).
  • Improvement: Optimised tile rendering for smoother performance.
  • Improvement: Added support for BMP image format.
  • Bug Fix: Fixed drag-and-drop not working on some mobile browsers.
  • Bug Fix: Corrected opacity slider behaviour.
v1.0.0 — 1 March 2026
  • Initial Release: First public version of AI Mosaic Studio.
  • Features: Base image upload, tile image upload, mosaic generation.
  • Features: Base opacity and tile opacity sliders.
  • Features: Export in PNG and JPG formats.
  • Features: HD (1280×720) export resolution.
  • Tech: MediaPipe integration for face detection.
  • Tech: Client-side processing with Web Workers.
v0.9.0 (Beta) — 15 January 2026
  • Beta Preview: Private beta release for testing and feedback.
  • Features: Basic mosaic generation with limited tile support.
  • Known Issues: Performance issues with large images. Limited browser support.
